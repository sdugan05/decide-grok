# Decide for Grok Bot

**Review preview. Not submitted, approved, or available as a Decide listing in
Grok Bot. Consumer installation is blocked on supported private wake pairing.**

Decide is an iPhone app that proposes one decision at a time. Yes authorizes the
exact displayed work; No defers it. A scoped Grok routine can extract stated
requirements from a connected Google document. Decide independently verifies the
returned source references before displaying a verified result.

The underlying development journey has passed with a real account. That does not
establish fresh-user installation, two-user isolation, or a marketplace listing.

This repository contains only the integration manifest, remote MCP configuration,
one skill, icon, license and review guidance. Application code, credentials,
private records and evidence are excluded. The configured stable endpoint is the
intended deployment destination; endpoint configuration is not deployment proof.

# Consumer installation status

**Not yet installable as a complete consumer workflow. Do not paste configuration
into Grok or use the publisher's development connection.**

The documented provider distribution route is a public Git package reviewed via
[Cursor's publisher application](https://cursor.com/marketplace/publish). Grok Bot
has an in-app Marketplace, but submission here does not establish that Decide is
approved or available there. No Decide listing or install link is claimed.

The intended flow, once prerequisites are verified:

1. Find Decide in Grok Bot's actual Marketplace and choose Add.
2. Use provider OAuth and confirm the person's own Apple-backed Decide identity.
3. A connection proposal joins the normal deck behind its current unanswered
   card. Only its Yes activates the scoped integration.
4. A supported provider flow privately pairs that person's own webhook-only
   routine. No copied secrets, URLs or task prompts.
5. Authorized document context produces a proposal in the normal deck. Native Yes
   authorizes one immutable assignment; No starts no work.
6. Execution and verification continue with the phone app closed. Results show
   the saved report and actual verification state. Account navigation can queue
   disconnect as another normal decision; reconnect never revives old approvals.

Step 4 has no verified consumer mechanism. The public routine documentation
describes manually copying a URL/key. A shared Bot template can carry a routine,
but no authenticated private handoff of its wake capability has been established.
Scheduled polling and manual secret forms are not implemented alternatives.

Fresh account onboarding/source selection, stable hosted execution, a reviewer
iPhone build and two real users' complete journeys must also pass before release.
Contact support for status; do not send credentials or private source material.
